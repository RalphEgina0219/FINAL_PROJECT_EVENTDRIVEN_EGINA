## 5. Problems found and fixed during P10
- **Team Leader dashboard too wide on phones (742 px at 390 px).** The new screenshot check found it after the first full run. The "Targets: medium: reply 8 h, resolve 48 h …" line in the Team targets card had no break point between its parts. It now wraps (`views/partials/team_targets.xian`). The final screenshot run reports **no page wider than the phone and no sideways-scrolling table**. The tool now also names the too-wide element (`tests/support/screenshots.mjs`).
- **check-connections could crash on Windows at exit** (`process.exit` while sockets were still closing). It now sets the exit code instead.
- **Blocked ports.** Node and browsers refuse to call some ports (for example 6000), and my first draft of the merge guide suggested 6000 for Accounting. The guide now uses 7000, lists the ports to avoid, and check-connections reports **BLOCKED PORT** instead of an unclear "TypeError".
- The merge scenarios first named buttons that do not exist ("Send pending now") and a dead-letter notification that CRM does not send. I checked every button name and message against the views and corrected them.
